# Estante Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two InkyPi plugins (Now listening, The shelf) plus a small conductor service so a Pimoroni Inky Impression 7.3" (2025, Spectra 6, 800x480) on the office bookshelf rotates between the audiobook Mathias is in, his audiobook shelf and his light-novel shelf, swaps on a button press relayed by the Ouvido daemon, and shows a Recado "message waiting" mark.

**Architecture:** A PIL-free core (`estante_lib.abs`, `.model`, `.state`) reads Audiobookshelf over HTTP and decides what is visible; a Pillow render layer (`.palette`, `.text`, `.render_now`, `.render_shelf`) draws 800x480 images whose every pixel is an exact Spectra 6 driver colour, so the inky driver's own quantize pass is a no-op and the panel shows exactly what we previewed. Two thin InkyPi plugin classes adapt that to `BasePlugin.generate_image`. A stdlib-only sidecar, `estante-ctl` (port 8360), owns rotation, button swaps, the 5-minute Now-listening watch and the badge, and drives InkyPi through its existing `POST /display_plugin_instance` route; InkyPi's own playlist cycle is parked at one year so the two never fight.

**Tech Stack:** Python 3.11+ (Pi OS Bookworm) and 3.12 (ryzen dev), Pillow, stdlib `urllib`/`http.server`/`threading`/`fcntl`, InkyPi at commit `df5fac46274a54b682f557a8ad4cde05dc41679a` (fatihak/InkyPi, 2026-10-26, GPL-3.0), pimoroni `inky==2.4.0` (E673 driver), pytest.

**Spec:** `/srv/appdata/html-gallery/ouvido.html` section 8 (public at https://docs.library.icu/ouvido.html), plus the decisions below. Executors read both.

## Decisions taken 2026-10-27 (Mathias, via AskUserQuestion)

- One Pi 3B+ on the office bookshelf carries panel, mic, blink(1) and the Ouvido daemon. No Pi Zero split.
- Panel: Inky Impression 7.3" 2025 edition. 800x480 landscape, Spectra 6 (black, white, yellow, red, blue, green), inky driver class `InkyE673`, EEPROM variants 22/26.
- The shelf = the 311 Audiobooks AND the 597 Light Novels as their own screen. Three screens rotate: "Now listening", "The shelf", "Light novels".
- Build and verify now on the ryzen against a fake display; nothing is on hardware until the panel arrives.

## Calls made by the planner (not agreed by Mathias, state them in the handoff)

- The sidecar owns rotation, not InkyPi's playlist timer. Reason: InkyPi's refresh thread wakes only once per cycle and its manual-display route does not advance the playlist index, so a button swap would re-show the same screen for an extra cycle, and nothing in InkyPi can poll every 5 minutes while a screen is shown. The playlist "Default" still holds the three instances (editable in InkyPi's web UI); InkyPi's cycle interval is set to its maximum, 24 hours; every display call we make resets InkyPi's own timer, so its cycle never fires while estante-ctl is alive (it would only rotate daily if the conductor died).
- Rotation timing lives in `/etc/estante/estante.json` (`rotate_minutes`, default 30), not InkyPi's settings page.
- A forced Now-listening redraw happens at most every `min_redraw_minutes` (default 10) even if chapters tick faster (Overgeared has 820 ten-minute chapters).
- Progress percent and time left use the item's current duration (`media.duration`), not the duration stored in the progress record (Overgeared grows while it renders).
- Now listening with nothing in progress shows the most recently finished book under "LAST LISTENED"; with no progress at all it shows "NOTHING PLAYING".
- Chapter line: "Chapter 1 of 61" when the chapter title is just "Chapter N"; otherwise "{title} ({n} of {count})".
- Shelf layouts: "pages" (10x5 = 50 covers per page, 64 px tiles) is the default for both libraries; "mosaic" (whole library on one screen, flat tiles) is available per instance.
- Covers in Now listening are contained (whole cover visible), not cropped; shelf tiles are square crops.
- Text is drawn anti-aliased and then snapped to the nearest ink (no dither) so glyph edges never speckle.

## Contracts with the sibling sessions (frozen 2026-10-27)

- Ouvido owns GPIO (BCM 5, 6, 16, 24). Estante uses SPI0 (BCM 8, 10, 11), DC 22, RESET 27, BUSY 17, I2C 2/3.
- Ouvido calls, all POST, 2 s timeout, no auth: `http://127.0.0.1:8360/swap` (press C, no body), `http://127.0.0.1:8360/show` with `{"screen":"the_shelf"}` (hold C), `http://127.0.0.1:8360/badge` with `{"message_waiting":bool,"dnd":bool,"from":"Jasmine"}` (optional `"count":int`) whenever a flag changes. All three answer 202 immediately; the panel redraw runs async because a Spectra 6 refresh takes up to ~32 s.
- `GET http://127.0.0.1:8360/state` returns `{"screen","screens","badge","busy","last_display","next_rotation","rotate_minutes"}`.
- Recado never calls Estante; its "waiting" reaches the panel through Ouvido's badge call.
- Ports on the Pi: InkyPi 80, Estante 8360, Ouvido 8600. Ouvido installs its Docker container first; InkyPi's native installer (SPI, I2C, reboot) runs after.

## Global Constraints

- No em dashes and no emojis anywhere: code, comments, copy, docs, commits, test names.
- Python: 4-space indent, LF, compatible with 3.11 (no 3.12-only syntax). `estante_lib.abs`, `.model`, `.state` and `ctl/estante_ctl.py` import nothing outside the stdlib. Pillow only in `.palette`, `.text`, `.render_*`, `.inkypi_glue` and the plugin classes.
- Shell scripts: `#!/bin/bash`, `set -e`, every variable quoted.
- Panel output: 800x480, mode "P" from the renderers with the driver palette attached; plugins return `.convert("RGB")`. Every pixel of a rendered image must be one of the six driver colours for the configured saturation (`palette.driver_palette(0.5)` = `[(0,0,0),(208,209,210),(231,222,35),(205,36,37),(30,29,174),(29,45,35)]`), proven by `palette.inky_pass` in tests.
- Audiobookshelf: GET only. Never call any route that writes progress, marks finished, or scans. The token is read from InkyPi's `.env` (`ABS_URL`, `ABS_TOKEN`) on the Pi and from `~/config/planetario.env` on the ryzen for previews and fixture recording. Tokens never land in git (fixtures are sanitized).
- Copy strings, exact: `NOW LISTENING`, `LAST LISTENED`, `NOTHING PLAYING`, `ESTANTE`, `read by {narrator}`, `{n} finished in {year}`, `{read} read  ·  {listening} listening  ·  {unread} to go`, `{subtitle}  ·  page {p} of {n}`, `{pct}% of the shelf read`, `Message from {from} waiting`, `{n} messages from {from} waiting`, `Message waiting`, `{n} messages waiting`, `QUIET`, `{h}h {mm}m left`.
- Fonts: EB Garamond (display and body) and Inter (labels), vendored from `/tmp/estante/EBGaramond.ttf` and `/tmp/estante/Inter.ttf` into `plugins/estante_lib/fonts/` (SIL OFL). Charts and labels stay in Inter.
- Ryzen CPU: tests and previews run in seconds; no long jobs. The InkyPi dev venv is the only pip install (one time).
- Repo: `~/estante`, branch `main`, license GPL-3.0 (plugins subclass InkyPi's `BasePlugin`). Commit per task, conventional prefix `feat(estante):` / `test(estante):` / `docs(estante):`. No Co-Authored-By trailers (CLAUDE.md rule).
- Fixtures are REAL data recorded from the live Audiobookshelf and sanitized (see Task 1). Expected numbers in tests are pinned from the fixture files with jq or a one-liner, never computed by the function under test.

  - `visible_key(nl: NowListening | None, badge: dict) -> tuple` = `(item_id or "none", chapter_idx, int(pct * 100), finished, bool(badge.get("message_waiting")), bool(badge.get("dnd")))`
